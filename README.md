# Free My TV para MXQ-4 Android 7

Build de compatibilidade do projeto [Free My TV](https://github.com/simbasjungles/free-my-tv),
fixado no commit `a9e10278b20de9e5700eeacb1503bca8145f220d`, com `minSdkVersion 25` para o MXQ-4 RK3229.

O APK deve ser instalado primeiro como aplicativo comum e testado antes de ser definido como launcher.
A licença MIT do projeto original está em `LICENSE`.
